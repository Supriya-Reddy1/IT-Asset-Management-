# IT Asset Management System (Frontend Version)

## Project Overview
The **IT Asset Management System** is a web-based interface that allows organizations to efficiently track and manage their IT assets. This frontend version focuses on providing a **clean, interactive, and responsive user interface** for adding, editing, deleting, and monitoring assets.  

---

## Project Concept
The system helps manage various IT assets such as:

- Laptops  
- Desktops  
- Servers  
- Network Devices  
- Software Licenses  

Users can **track asset status, assigned personnel, and purchase dates**, as well as visualize asset data through charts.

---

## Features Implemented (Frontend Version)

1. **Structured HTML Layout**  
   - Clear sections for Header, Asset Form, Asset Table, and Charts.  
   - Responsive and accessible design.  

2. **CSS Styling**  
   - Professional color scheme and layout.  
   - Flexbox used for headers, forms, and charts.  
   - Responsive tables and neatly spaced sections.  

3. **JavaScript Interactivity**  
   - **Add, Edit, Delete assets** dynamically.  
   - **Search functionality** to filter assets in real-time.  
   - **Export assets as CSV** for record-keeping.  
   - Purchase Date included in asset records.  

4. **Professional UI/UX Enhancements**  
   - Well-aligned buttons and input fields.  
   - Proper spacing between search input and asset table.  

---

## Future Improvements (Backend Integration)

- **Database Integration:** Connect to MySQL/PostgreSQL to store asset data persistently.  
- **User Authentication:** Implement secure login/logout functionality.  
- **Automated Alerts & Notifications:** For license expiry, maintenance, or warranty ending soon.  
- **Advanced Analytics:** Detailed reports and downloadable PDF exports.

## Getting Started

1. **Clone the repository**:  
   ```bash
   git clone <your-repo-link>
   ```

2. **Open `index.html`** in a web browser.  

3. **Interact with the system**:  
   - Add, edit, or delete assets.  
   - Search assets in the table.  
   - Export data as CSV.
